# Personal Expense Analysis using Python

## Project Overview
This project analyzes personal expenses using Python, Pandas, and Matplotlib.

## Dataset
The dataset contains 37 expense transactions with 6 columns:
- Date
- Category
- Subcategory
- Description
- Amount_INR
- Payment_Method

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Total, average, highest, and lowest expenses
- Category-wise expense analysis
- Payment method analysis
- Monthly expense analysis
- Data quality checks
- Expense charts

## Key Findings
- Total expenses: Rs. 24,053
- Highest spending category: Food (Rs. 7,820)
- Most-used payment method: UPI (Rs. 16,947)
- Highest spending month: March 2026 (Rs. 8,453)
